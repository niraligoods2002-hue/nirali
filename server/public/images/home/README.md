# Homepage ad artwork

Add campaign images in this folder, then list their public paths in `HOME_ADVERTISEMENT_IMAGES` in `server/.env`.

Example:

```env
HOME_ADVERTISEMENT_IMAGES=/images/home/diwali-desktop.jpg,/images/home/wedding-edit.jpg
```

Use wide landscape artwork (around 1800 × 700 px works well). The homepage supports up to five images and rotates through them automatically. Leave the setting empty to feature in-stock highlighted products instead.
